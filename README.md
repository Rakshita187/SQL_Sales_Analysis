## Project Overview

This project analyzes sales data using SQL queries.

## Tools Used

- MySQL
- SQL

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- SUM()
- COUNT()
- AVG()
- CASE
- JOIN
- Subqueries

## Analysis Performed

- Revenue by category
- Number of orders by region
- Average order value
- Top 10 customers by spending
- Top customer
- Order value classification
- Region-wise revenue
- Category-wise average unit price

## Objective

To analyze sales data and extract useful business insights using SQL.
